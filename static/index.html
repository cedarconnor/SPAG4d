Workflow

  1. Upload a 2:1 equirectangular panorama (JPG/PNG)
  2. Adjust parameters below (defaults work well for most scenes)
  3. Convert — runs depth estimation + SPAG conversion (~1-2s)
  4. Preview in the 3D viewer: left-click orbit, right-click pan, scroll zoom
  5. Refine (optional) — GSFix3D disocclusion repair
  6. Download as PLY for Blender, SuperSplat, or any 3DGS viewer

Conversion Parameters

Depth Model
DA360 (default) = scale-invariant disparity with 360° padding. DAP = metric depth for panoramas.
Stride
Pixel stride for Gaussian generation. 1 = max quality, 2 = balanced (default), 4 = fast preview.
Depth Range
Auto-computed from depth map statistics. Adapts to indoor (3m rooms) and outdoor (100m forests) automatically. Override with manual values if needed.
Sky Cutoff
Auto = 95th percentile of depth. Points beyond this are removed.
Edge Cutoff
Removes edge-on splats behind objects (grazing angle). 65° = default, removes depth discontinuity stripes. 90° = off.
Floaters Cleanup
Outlier removal strength. 0.3 = default. Removes floating splats.
Sparse Filter
Removes isolated splats. 0.3 = default. Cleans up sparse regions.
Depth Scale
Global depth multiplier. Adjusts overall scene scale.

Splat Refinement (GSFix3D)

After conversion, use refinement to fill disocclusion holes. The pipeline generates novel-view cameras, detects holes via alpha thresholding, repairs them with a scene-adapted diffusion model (GSFix3D), then optimizes the 3DGS via differentiable rendering.

Cameras
Number of novel-view cameras. 36 = 12 directions x 3 depths. More cameras detect more holes but take longer.
Rounds
Refinement iterations. Each round re-renders, finds remaining holes, and repairs them. Stops early when holes < 2%.
Finetune Steps
GSFixer scene adaptation. 500 steps (~5 min) teaches the model this scene's appearance before repairing holes.
Quick Tips: Start with 36 cameras and 1 round for a quick test. The pipeline auto-detects which cameras have significant holes and only repairs those. Use 3 rounds for thorough coverage.
