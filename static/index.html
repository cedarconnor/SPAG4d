Workflow

  1. Upload a 2:1 equirectangular panorama (JPG/PNG)
  2. Adjust parameters below (defaults work well for most scenes)
  3. Convert — runs depth estimation + SPAG conversion (~1-2s)
  4. Preview in the 3D viewer: left-click orbit, right-click pan, scroll zoom
  5. Refine (optional) — OmniRoam v2 disocclusion repair
  6. Download as PLY for Blender, SuperSplat, or any 3DGS viewer

Conversion Parameters

Generator
DA360 (default) = scale-invariant disparity with 360° padding. DAP = metric depth for panoramas. SHARP 360 = per-face ML prediction for higher quality (slower).
Stride
Pixel stride for Gaussian generation. 1 = max quality, 2 = balanced (default), 4 = fast preview.
Depth Range
Auto-computed from depth map statistics. Adapts to indoor (3m rooms) and outdoor (100m forests) automatically. Override with manual values if needed.
Sky Cutoff
Auto = 95th percentile of depth. Points beyond this are removed.
Edge Cutoff
Removes edge-on splats behind objects (grazing angle). 65° = default, removes depth discontinuity stripes. 90° = off.
Floaters Cleanup
Outlier removal strength. 0.3 = default. Removes floating splats.
Sparse Filter
Removes isolated splats. 0.3 = default. Cleans up sparse regions.
Depth Scale
Global depth multiplier. Adjusts overall scene scale.

Splat Refinement (OmniRoam v2)

After conversion, use refinement to fill disocclusion holes. OmniRoam generates trajectory-coherent novel views, then optimizes the 3DGS to incorporate them.

Trajectories
Auto = gap-directed (recommended). All = all cardinal directions. Forward/Right etc. for targeted coverage.
Rounds
Refinement iterations. Each round generates new views and re-optimizes. Stops early when holes < 2%.
Tier-2 Weight
Weight for OmniRoam pseudo-views during optimization. Lower = more conservative. Range 0.05–0.50.
Quick Tips: Start with Auto trajectories and 1 round for a quick test. Use 3 rounds for thorough coverage.
