Workflow

  1. Upload a 2:1 equirectangular panorama (JPG/PNG)
  2. Adjust parameters below (defaults work well for most scenes)
  3. Convert — DAP depth estimation runs first, then SHARP Gaussian generation
  4. Preview in the 3D viewer: orbit with mouse, scroll to zoom
  5. Download as PLY for use in Blender, SuperSplat, or any 3DGS viewer

Parameters

Projection
Cubemap (6) = faster, 6-face cubemap. Icosa (20) = 20 tangent faces, less distortion, better pole quality.
Face Size
SHARP processing resolution per face. Higher = better detail but more VRAM/time.
Depth Range
Valid depth in meters. Points outside this range are clipped.
Sky Cutoff
Distance (meters) beyond which points are removed.
Grid Jitter
Breaks regular dot patterns from SHARP's grid. Default 0.03 is subtle.
Floaters Cleanup
Statistical outlier removal. 0 = off, higher = more aggressive.
Quick Tips: For indoor scenes, reduce Sky Cutoff to 30m. For landscapes, use Icosa (20) projection for best pole quality.
